# Шинторг WMS — Складской учёт

Информационная система складского учёта ООО «Шинторг».

## Быстрый старт (Docker)

### 1. Клонировать / скопировать проект

```bash
cd shintorg_wms
```

### 2. Изменить SECRET_KEY

В файле `docker-compose.yml` замените значение `SECRET_KEY` на произвольную длинную строку:

```yaml
SECRET_KEY: ваш-секретный-ключ-не-менее-32-символов
```

### 3. Запустить

```bash
docker compose up -d --build
```

Приложение будет доступно по адресу: **http://localhost:8000**  
В локальной сети: **http://192.168.X.X:8000**

### 4. Создать первого администратора

```bash
docker compose exec app python create_admin.py
```

Следуйте инструкциям на экране.

## Роли пользователей

| Роль | Ключ |
|---|---|
| Администратор | `admin` |
| Менеджер по продажам | `manager` |
| Кладовщик | `storekeeper` |
| Грузчик | `loader` |
| Бухгалтер | `accountant` |

---

## Первоначальная настройка (через браузер)

После входа под администратором:

1. **Адреса** — создать зоны, ряды, при необходимости стеллажи и уровни, затем адреса хранения.
2. **Товары** — добавить товарные позиции с указанием адреса хранения.
3. **Пользователи** — создать учётные записи для сотрудников.
4. **Приёмка** — оприходовать начальные остатки через карточку товара.

## Управление

```bash
# Остановить
docker compose down

# Остановить с удалением данных (осторожно!)
docker compose down -v

# Посмотреть логи
docker compose logs -f app

# Перезапустить приложение
docker compose restart app
```

## Резервное копирование

```bash
# Бэкап базы данных
docker compose exec db pg_dump -U shintorg shintorg_wms > backup_$(date +%Y%m%d).sql

# Восстановление
docker compose exec -T db psql -U shintorg shintorg_wms < backup_20240101.sql
```
